# SEO Content

Write for the searcher first; search engines reward content that fully satisfies intent.

## 1. Determine intent

For the target keyword, classify intent: **informational** (how/what/why), **commercial** (best, vs, review), **transactional** (buy, pricing, signup), or **navigational**. The format must match: a "how to" query wants a guide, a "best X" query wants a comparison, not a product page.

You cannot see live search volumes or rankings unless a tool provides them. Don't make up search volumes or difficulty scores; label any estimates as estimates and suggest the user verify in their SEO tool.

## 2. Content brief (when planning)

```markdown
**Primary keyword:** ...
**Secondary / related keywords:** ...
**Search intent:** ...
**Target reader:** ...
**Angle (why ours is better than what ranks now):** ...
**Suggested title (≤60 chars):** ...
**Meta description (≤155 chars):** ...
**URL slug:** /short-descriptive-slug
**Outline:** H2/H3 structure with notes per section
**Questions to answer (People Also Ask style):** ...
**Internal links to add:** ...
**Target length:** based on depth needed, not word-count padding
```

## 3. Writing

- Put the primary keyword in the title, H1, first 100 words, and at least one H2 — naturally, never stuffed.
- Answer the core question in the first 2–3 sentences (featured-snippet friendly), then go deeper.
- Use descriptive H2/H3s that work as a table of contents.
- Use lists, tables and steps where they help scanning.
- Add original value: examples, data the user owns, opinions, screenshots, templates. Flag where first-hand experience should be added (E-E-A-T).
- Include an FAQ section for related questions when it fits.
- End with a clear next step / CTA relevant to the intent.

## 4. On-page audit (when optimizing existing content)

If the content lives in the repo (Markdown, MDX, HTML, CMS JSON), read it directly. Check and report:

- Title tag and meta description: present, unique, within length, keyword included, compelling.
- Single H1; logical heading hierarchy.
- Intent match and content gaps versus the topic.
- Image `alt` text, descriptive file names.
- Internal and external links; broken or generic anchor text ("click here").
- Canonical, `noindex`, Open Graph / Twitter tags, structured data (JSON-LD) where relevant.
- Readability: sentence length, walls of text.

Return a prioritized list: **High / Medium / Low** impact, each with the exact fix. Offer to apply the fixes.
